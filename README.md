# Investment calculator

Enter initial investment, annual contribution, expected return and duration; the table recalculates year by year. Built while learning React fundamentals: derived state, lists and keys, controlled inputs, and keeping formatting logic in `util/investment.js`.

React 18 + Vite.

```bash
npm install && npm run dev
```
